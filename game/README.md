# 潮鳴りの狩場

夕凪の石浜で、大剣を使ってタルンルソルクやサボッテンアンボンを討伐する三人称3Dアクションゲーム。スマホは横画面推奨。縦画面でも全操作を使えます。Three.js・TypeScript・Viteで構築し、プレイ時にアカウント、APIキー、外部サービスは不要です。

## 起動

Node.js 22 LTS を推奨します。ZIPを解凍し、`package.json` があるフォルダーで実行します。

```sh
npm ci
npm run dev
```

ターミナルに表示されるURLを開きます。PCとiPhoneが同一のネットワークにいる場合は、`npm run dev -- --host 0.0.0.0` で起動し、表示される Network URL をiPhoneのSafariで開けます。

```sh
npm run build
npm run preview
```

同梱の `dist/` はビルド済みの配信用ファイルです。任意の静的HTTPホスティングに、フォルダー内の構造を保って配置できます。ローカル確認にもHTTP配信を使います。`dist/index.html` をファイルとして直接開くと、ブラウザの制約でJavaScriptモジュールやGLBを読み込めない場合があります。

## GitHub Pagesで公開

1. GitHubのリポジトリを用意し、`package.json` と `.github/workflows/pages.yml` を含むソース一式をリポジトリのルートに配置します。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. `main` へプッシュします。プッシュ済みの場合は、**Actions → Deploy static game to GitHub Pages → Run workflow** を実行します。
4. デプロイ完了後、PagesのURLを開きます。リポジトリ名を含むサブパスでもGLBとJSを読み込める構成です。

## 操作

| 操作 | iPhone | PC |
|---|---|---|
| 移動 | 画面左下を押してドラッグ | WASD / 矢印キー |
| カメラ | 空いている画面を左右にスワイプ | 画面を左右にドラッグ |
| 通常攻撃 | 斬撃 | J |
| 3段コンボ | 斬撃中に次の斬撃を入力 | 振っている間に J を再入力 |
| 溜め攻撃 | 溜めを長押しして離す | K を長押しして離す |
| 回避 | 回避 | Space |
| ガード | ガードを長押し | L を長押し |
| ロックオン | 照準 | Q |
| 一時停止 | 右上の一時停止ボタン | Esc / P |

戦闘カメラの見下ろす角度は固定で、左右に回せます。視界を遮る手前の岩や木は一時的に透け、壁際でもカメラの距離を保ちます。画面左下のスティックの周囲からも移動を始められます。スティック中央から外へ短くドラッグすると通常移動の最高速度に達します。正面からの攻撃は、スタミナを消費してガードできます。回避は転がり始めてすぐの短い間に無敵が発生します。斬撃の終わり際に押した回避は短時間記憶され、回避できるタイミングで発動します。表示されるダメージの下に命中部位が出ます。頭はダメージが通りやすく、脚を狙うと転倒を誘えます。

| 敵の攻撃 | 予兆と対処 |
|---|---|
| 腕薙ぎ | 片腕を引く。横か背後へ回る |
| 突進 | 身を屈めて進行方向を決める。進行方向との直角に抜ける |
| 回転攻撃 | 上体をひねる。身体から距離を取る |
| 跳躍プレス | 身を沈め、着地予定地点に輪が出る。外へ出る |
| 潮鳴り震波 | 両腕を上げて地面を打つ。広がる波のタイミングに合わせて回避する |

怒りは体力52％以下で、現在の行動に区切りがついた時点で発動します。専用の咆哮と体色変化のあと、射程内にいる相手には距離が近くても震波を使います。跳躍や震波の頻度が上がり、連続攻撃と三重の震波が加わります。

## タルンルソルクのモデルとモーション

`public/models/monster001_v4.glb` は添付GLBと同一バイト列です。1メッシュ、17,478頂点、34,952三角形、1マテリアル。画像テクスチャは埋め込まれておらず、顔や体の色は頂点カラー `COLOR_0` です。骨格の胴 `Root` の子に `Head`、`Arm.L`、`Arm.R`、`Leg.L`、`Leg.R` が接続されています。Three.js読み込み後はドットが除かれた名前になります。

| GLBのクリップ | 長さ | ゲーム内の用途 |
|---|---:|---|
| Idle | 2.00秒 | 待機 |
| Run | 0.70秒 | 走行・速度を下げた歩行・加速した突進 |
| Roar | 1.60秒 | 索敵後と怒りの咆哮 |
| Attack | 1.00秒 | 腕薙ぎ。攻撃予兆・攻撃・硬直に区分 |
| Jump | 1.20秒 | 跳躍プレス |
| Spin | 1.20秒 | 回転攻撃 |
| Defeat | 1.50秒 | 討伐 |
| 既存骨格に追加したキーフレーム | ゲーム内の状態に同期 | 旋回・被弾・怯み・転倒・跳躍予兆・潮鳴り震波 |

元の骨格の各ボーンに対して追加トラックを生成し、状態遷移は約120〜160ミリ秒でブレンドします。ポーズごとの下端を求め、転倒や討伐で地面に埋まる位置を補正します。部位の当たり判定も対応するボーンを追います。

```sh
npm run inspect
npm run inspect -- public/models/another-monster.glb
```

## サボッテンアンボン

モンスターIDは `MON_001`、体力1,000、怒り閾値550、移動速度2.3。設定と調整箇所は `src/sabottenanbon/config.ts` にまとめています。モデルと棘のGLBは `public/models/sabottenanbon/` にあります。元のGLBの骨格、外見、クリップをそのまま読み込み、発射時のボーン姿勢をサンプリングします。

| 技 | 行動 | クールダウン |
|---|---|---:|
| 三連爆ぜ棘 | 0.96、1.32、1.68秒に頭から3本ずつ。直撃10、着弾爆発16。棘1本につき同じハンターへのダメージは1回 | 3秒 |
| 焼き込みブレス | 怒り中の正面。2.356秒に両枝から棘6本。口の向きに追従するブレスは2.65秒まで、9ダメージ | 7秒 |
| 火輪と爆ぜ棘 | 怒り中に別の技を終えてから使う。回転ブレスは11ダメージ。棘27本を撒き、4.62秒に一斉爆発。重複範囲でも30ダメージ1回。6.00秒まで硬直 | 18秒 |

クールダウンは技の終了または中断から開始します。棘は円形の場外境界または地面へ着弾します。ブレスは場外を円に沿う接線で区切り、足元の地面高さを描画と判定に共用します。低画質はBloomを使いません。中・高画質で浮動小数点の描画ターゲットを使える環境では炎のみにBloomを加えます。

## 新規モンスター・武器・フィールド

- モンスターを追加するにはGLBを `public/models/` に置き、`src/config.ts` に `MonsterData` を追加します。ID、名称、モデルと縮尺・向き・接地オフセット、HP・移動速度・攻撃倍率、ボーン名、部位中心・半径・倍率、攻撃の射程と時間、有効な攻撃タイプ、AIと怒り条件、クリップ名を設定します。タイトルに並べる対象は `src/main.ts` の `roster` で設定します。
- `src/monster-model.ts` が骨格・クリップ・部位情報を解決します。既定の動作は胸部一体の二足骨格を想定しています。特殊な骨格には既存クリップを割り当てるか、生成トラックを追加します。5種の攻撃タイプを流用する場合はデータで調整できます。新しい判定形状や行動タイプの追加箇所は `src/battle.ts` です。
- 大剣の威力・タイミング・移動速度は `src/config.ts`、武器外形と構えは `src/hunter.ts`、攻撃ステートは `src/battle.ts` にあります。武器を増やす際は武器データとモデルを追加し、攻撃系列に対応するポーズや専用状態を実装します。
- フィールド名、開幕位置、行動範囲は `src/config.ts`。景観、地面高さ、障害物、カメラを遮る地形の表示制御は `src/world.ts` にあります。

## 画質と検証

低・中・高は描画解像度の上限、影マップ、同時エフェクト数を切り替えます。タッチ端末の初期値は「低」です。描画バッファは端末のDPRと総ピクセル数で制限し、低画質は影マップを間引いて更新します。ゲーム本体は固定時間刻みで進みます。岩・草・樹木はインスタンス描画を使い、ヒットエフェクトとダメージ表示は再利用します。再挑戦でGLBを読み直しません。

デスクトップChromiumでキーボード・マウス操作、攻撃の判定時刻、部位ダメージ・コンボ・溜め、敵の5攻撃、回避、ガード、転倒からの復帰、討伐成功・失敗と再挑戦を確認しました。iPhone 13向けのChromiumエミュレーションでは、縦・横とも移動＋斬撃、移動＋回避、スワイプ視点、ロックオンを確認しました。ビルド済みファイルでは、リポジトリ名を模したサブパスでの起動と、GLBが見つからない場合のエラー画面を確認しました。

Safariの実機動作と、iPhoneでの30／60FPSは未計測です。
