# メガネハント

夕凪の石浜で、大剣を使ってタルンルソルクやサボッテンアンボンを討伐する三人称3Dアクションゲーム。スマホは縦画面専用です。横にすると一時停止します。PCでは縦長のプレイ画面で操作できます。Three.js・TypeScript・Viteで構築し、プレイ時にアカウント、APIキー、外部サービスは不要です。

## 起動

Node.js 22 LTS を推奨します。ZIPを解凍し、`package.json` があるフォルダーで実行します。

```sh
npm ci
npm run dev
```

ターミナルに表示されるURLを開きます。PCとiPhoneが同一のネットワークにいる場合は、`npm run dev -- --host 0.0.0.0` で起動し、表示される Network URL をiPhoneのSafariで開けます。

```sh
npm run build
npm run preview
```

同梱の `dist/` はビルド済みの配信用ファイルです。任意の静的HTTPホスティングに、フォルダー内の構造を保って配置できます。ローカル確認にもHTTP配信を使います。`dist/index.html` をファイルとして直接開くと、ブラウザの制約でJavaScriptモジュールやGLBを読み込めない場合があります。

## GitHub Pagesで公開

1. GitHubのリポジトリを用意し、`package.json` と `.github/workflows/pages.yml` を含むソース一式をリポジトリのルートに配置します。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. `main` へプッシュします。プッシュ済みの場合は、**Actions → Deploy static game to GitHub Pages → Run workflow** を実行します。
4. デプロイ完了後、PagesのURLを開きます。リポジトリ名を含むサブパスでもGLBとJSを読み込める構成です。

## 操作

| 操作 | iPhone | PC |
|---|---|---|
| 移動 | 移動スティックをドラッグ | WASD / 矢印キー |
| カメラ | 空いている画面を左右にスワイプ | 画面を左右にドラッグ |
| 通常攻撃 | 斬撃 | J |
| 3段コンボ | 斬撃中に次の斬撃を入力 | 振っている間に J を再入力 |
| 溜め攻撃 | 溜めを長押しして離す | K を長押しして離す |
| 回避 | 回避 | Space |
| ガード | ガードを長押し | L を長押し |
| ロックオン | 敵のアイコンをタップ、照準で解除 | 敵のアイコンをクリック、Qで切替 |
| 一時停止 | 一時停止ボタン | Esc / P |

戦闘カメラの見下ろす角度は固定で、左右に回せます。視界を遮る手前の岩や木は一時的に透け、壁際でもカメラの距離を保ちます。スティックの周囲からも移動を始められます。タイトルと一時停止メニューの「操作配置」で、スティックと各ボタンの位置や大きさを個別に調整できます。「保存」でブラウザに記録し、「標準に戻す」で標準配置に戻せます。敵ごとに小さなアイコンが表示されます。タップまたはクリックした敵をロックオンし、選択したアイコンを強調します。画面外の敵は画面の端にアイコンが表示されます。スティック中央から外へ短くドラッグすると通常移動の最高速度に達します。正面からの攻撃は、スタミナを消費してガードできます。回避は転がり始めてすぐの短い間に無敵が発生します。斬撃の終わり際に押した回避は短時間記憶され、回避できるタイミングで発動します。表示されるダメージの下に命中部位が出ます。頭はダメージが通りやすく、脚を狙うと転倒を誘えます。

| 敵の攻撃 | 予兆と対処 |
|---|---|
| 腕薙ぎ | 片腕を引く。横か背後へ回る |
| 突進 | 身を屈めて進行方向を決める。進行方向との直角に抜ける |
| 回転攻撃 | 上体をひねる。身体から距離を取る |
| 跳躍プレス | 身を沈め、着地予定地点に輪が出る。外へ出る |
| 潮鳴り震波 | 両腕を上げて地面を打つ。広がる波のタイミングに合わせて回避する |

怒りは体力52％以下で、現在の行動に区切りがついた時点で発動します。専用の咆哮と体色変化のあと、射程内にいる相手には距離が近くても震波を使います。跳躍や震波の頻度が上がり、連続攻撃と三重の震波が加わります。

## タルンルソルクのモデルとモーション

`public/models/monster001_v4.glb` は添付GLBと同一バイト列です。1メッシュ、17,478頂点、34,952三角形、1マテリアル。画像テクスチャは埋め込まれておらず、顔や体の色は頂点カラー `COLOR_0` です。骨格の胴 `Root` の子に `Head`、`Arm.L`、`Arm.R`、`Leg.L`、`Leg.R` が接続されています。Three.js読み込み後はドットが除かれた名前になります。

| GLBのクリップ | 長さ | ゲーム内の用途 |
|---|---:|---|
| Idle | 2.00秒 | 待機 |
| Run | 0.70秒 | 走行・速度を下げた歩行・加速した突進 |
| Roar | 1.60秒 | 索敵後と怒りの咆哮 |
| Attack | 1.00秒 | 腕薙ぎ。攻撃予兆・攻撃・硬直に区分 |
| Jump | 1.20秒 | 跳躍プレス |
| Spin | 1.20秒 | 回転攻撃 |
| Defeat | 1.50秒 | 討伐 |
| 既存骨格に追加したキーフレーム | ゲーム内の状態に同期 | 旋回・被弾・怯み・転倒・跳躍予兆・潮鳴り震波 |

元の骨格の各ボーンに対して追加トラックを生成し、状態遷移は約120〜160ミリ秒でブレンドします。ポーズごとの下端を求め、転倒や討伐で地面に埋まる位置を補正します。部位の当たり判定も対応するボーンを追います。

```sh
npm run inspect
npm run inspect -- public/models/another-monster.glb
```

## 戦闘BGMと効果音

戦闘中に「Shadow Protocol」がループ再生されます。タイトルと一時停止メニューの「戦闘BGM」で「あり」「なし」を切り替えられます。初期設定は「あり」です。「BGM音量」と「効果音音量」はそれぞれ調整でき、0%で消音になります。設定はブラウザに保存されます。

効果音はモノラル32kHz／16bit PCMのWAVです。武器の振り始め、命中、魔弾の発射、炎の波、分身の召喚、紫煌機の結晶や光線など、戦闘側のイベントから再生します。同じ音の再生速度と音量を少しずつ変え、同時発音数と最終出力を制限します。モンスターの声はこれらの音とは別に追加できます。

`public/audio/sfx/` の素材は、NumPyとSciPyを使う `python3 tools/synthesize_sfx.py` で再生成できます。

## 世界ランキング

タイトルの「世界ランキング」で、大剣と魔法使いの部門ごとに、各ボスの上位20件を確認できます。討伐成功画面で公開ニックネームを入力して登録します。アカウント登録は不要です。同じブラウザの記録は、ボスと部門ごとに自己ベストだけが掲載されます。部門を分ける前の記録は大剣部門に表示されます。

「挑戦者」の人数は、モンスター別に出撃・記録データから集計します。同じブラウザでの再挑戦と大剣・魔法使いの重複は1人分です。表示時は閲覧中のブラウザの分を除きます。別の端末やブラウザでは別々に数えられます。

順位にはサーバーが測ったクエスト開始から討伐通知までの時間を使います。一時停止中の時間も含まれます。ブラウザで動く戦闘の内容をサーバーが再現・検証する仕組みはありません。通信できない場合にも戦闘はできます。

ランキングのデータは Supabase に保存します。公開APIの設定は `src/rankings.ts`、テーブルとAPIの定義は `supabase/migrations/` にあります。ブラウザには公開用キーだけを含めます。

## 新規モンスター・武器・フィールド

- モンスターを追加するにはGLBを `public/models/` に置き、`src/config.ts` に `MonsterData` を追加します。ID、名称、モデルと縮尺・向き・接地オフセット、HP・移動速度・攻撃倍率、ボーン名、部位中心・半径・倍率、攻撃の射程と時間、有効な攻撃タイプ、AIと怒り条件、クリップ名を設定します。タイトルに並べる対象は `src/main.ts` の `roster` で設定します。
- `src/monster-model.ts` が骨格・クリップ・部位情報を解決します。既定の動作は胸部一体の二足骨格を想定しています。特殊な骨格には既存クリップを割り当てるか、生成トラックを追加します。5種の攻撃タイプを流用する場合はデータで調整できます。新しい判定形状や行動タイプの追加箇所は `src/battle.ts` です。
- 大剣の威力・タイミング・移動速度は `src/config.ts`、武器外形と構えは `src/hunter.ts`、攻撃ステートは `src/battle.ts` にあります。武器を増やす際は武器データとモデルを追加し、攻撃系列に対応するポーズや専用状態を実装します。
- フィールド名、開幕位置、行動範囲は `src/config.ts`。景観、地面高さ、障害物、カメラを遮る地形の表示制御は `src/world.ts` にあります。

## 画質と検証

低・中・高は描画解像度の上限、影マップ、同時エフェクト数を切り替えます。タッチ端末の初期値は「低」です。描画バッファは端末のDPRと総ピクセル数で制限し、低画質は影マップを間引いて更新します。ゲーム本体は固定時間刻みで進みます。岩・草・樹木はインスタンス描画を使い、ヒットエフェクトとダメージ表示は再利用します。再挑戦でGLBを読み直しません。

デスクトップChromiumでキーボード・マウス操作、攻撃の判定時刻、部位ダメージ・コンボ・溜め、敵の5攻撃、回避、ガード、転倒からの復帰、討伐成功・失敗と再挑戦を確認しました。iPhone 13向けのChromiumエミュレーションでは、縦画面でのタッチ操作、横向きにしたときの一時停止、操作配置の保存、レボテンシの召喚・討伐に応じた照準の増減を確認しました。ビルド済みファイルでは、リポジトリ名を模したサブパスでの起動と、GLBが見つからない場合のエラー画面を確認しました。

Safariの実機動作と、iPhoneでの30／60FPSは未計測です。

## レボテンシ

- HP 1,500。顎はダメージ1.3倍。
- 天裂光線は1.2秒溜めて1.5秒照射し、照射中はゆっくり追尾。狂転突撃は0.7秒の予兆から回転して前進。
- 反転竜巻に命中するとダメージを受け、移動方向が5秒間反転する。
- HP50%以下で無敵バリアを展開し、HP120の分身体を2体召喚。バリア中は本体のHPが毎秒3回復する。分身体は本体の攻撃力の65%でスピン攻撃を行う。2体撃破でバリアが壊れ、本体が4秒間ダウンする。
- HP30%以下で怒り状態になり、移動速度が1.3倍、攻撃力が1.25倍になる。

レボテンシの世界ランキングを稼働させるには、公開先のデータベースに `supabase/migrations/20261125223500_revotenshi_ranking.sql` を適用する。

## 紫煌機

モンスターIDは `shikouki`。HPは5,000で、既存の大剣で約2分を目標に調整。HP60%以下で怒り、25%以下で暴走する。暴走後の最初の行動「紫煌天獄」では、結晶柱48本、回転光線、放射状の結晶弾、急降下と着地衝撃波を展開する。着地後はダウンする。

生成された結晶には接触判定がある。大剣で破壊でき、紫煌機の斬撃を受けた結晶は予告後に爆発する。紫煌光線に当たると、結晶の位置から追加の光線が分岐する。

HPと行動の調整は `src/shikouki/config.ts`、判定とタイムラインは `src/shikouki/attacks.ts`。世界ランキングには `supabase/migrations/20261126033611_shikouki_ranking.sql` を使用する。

## プレイヤーキャラクター「フレア」

「狩りに出る」から大剣ハンターかフレアを選びます。フレアは J／魔弾でエネルギーショット、K／フレアで現在使える最上位の範囲攻撃を発動します。エネルギーの初期値は0、上限は300です。魔弾の射程は8m、発射間隔は0.9秒で、弾が飛んだ距離が2mまでは40ダメージで、そこから直線的に減衰し、射程端の8mで1ダメージになります。実ダメージの37.5%をエネルギーとして回収します。

| 技 | ダメージ | 消費エネルギー | 半径 |
|---|---:|---:|---:|
| フレアⅠ | 140 | 75 | 2.5m |
| フレアⅡ | 400 | 180 | 4m |
| フレアⅢ | 880 | 300 | 6m |

フレアのモデルは選択した狩りの開始時に読み込み、同じページを開いている間は再利用します。配信用の `models/flare/v12.gz.00` から `v12.gz.08` には、元の形状、テクスチャ、11種類のクリップを収録したGLBを圧縮して格納しています。

## コウエン鳥

★1の炎翼鳥種。IDは `kouencho`。HP 2,500、通常移動 2.18 m/s。
空中で翼を動かし、攻撃後は低空で止まる。大剣の部位補正は1.16〜1.34倍。
HP40%以下で怒り、移動速度1.15倍、攻撃動作と攻撃力1.10倍。火羽の着弾予告と火炎放射の持続時間、攻撃後の隙、全域炎輪の時間は固定。

| 技 | ダメージ（通常／怒り、プレイヤーHP130） | 予備動作 | 隙 |
|---|---:|---:|---:|
| 火炎弾 | 8／9（1発） | 1.2秒 | 1.5秒 |
| 火翼急襲 | 20／21 | 1.5秒 | 2.5秒 |
| 火翼回転 | 13／14 | 0.9秒 | 1.8秒 |
| 火羽落とし | 12／13（着弾1か所） | 1秒＋着弾予告1.5秒 | 2秒 |
| 火炎放射 | 20／21（1回の放射の最大値） | 1.3秒 | 2秒 |
| 全域炎輪 | 33／36 | 3秒＋回転0.8秒 | 4秒 |

全域炎輪はHP60%・25%以下で各1回。閾値を同時に超えた場合は、疲労と通常技を挟む。
